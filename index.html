01 / THE NETWORK

Shared controls knowledge moves everyone forward.

The INFN-A EPICS controls network promotes common guidelines, reusable code and the exchange of experience across the INFN community.

This GitHub organization is a practical home for IOC images, support modules, operator interfaces, EPIK8S charts and related software. It connects engineering work in facilities with tools that other teams can inspect and adapt.

Meet the INFN-A EPICS network ↗

The primary responsibility of this group, as outlined in the “Epics Council” document, is to provide and disseminate guidelines and best practices to the broader INFN community. This extends beyond sharing code and hardware catalogs; it also includes sharing experiences to prevent the duplication of efforts and ensure efficient resource utilization.

07 / A CONNECTED ECOSYSTEM

From live controls to lasting knowledge.

EPIK8S deploys and operates EPICS controls. ARGUS Knowledge Hub connects the equipment, configuration, incidents, activities and documents around those systems for accelerator control room teams.

ARGUS can import EPIK8s beamline configuration and help IOC engineers inspect templates, draft entries and check them before deployment.
